# Picasso (picasso)

Picasso is an image downloading and caching library for Android, focused on simplicity and minimal disk space usage. It is an open-source project by Square. Picasso is a client-side library, not a hosted HTTP API.

## APIs

Picasso is an Android client-side library and does not expose an HTTP API. There is no OpenAPI specification because there is no REST/HTTP service to describe. Developers integrate Picasso via Maven/Gradle and call its Java/Kotlin methods directly.
